So liest du das Bild

  • Ablauf: Start a call → Start call → Invite → Copy link (Anna kommt dazu) → Leave → End call → Back to start.
  • Einladung: Chip „Einladung öffnen“ zeigt dasselbe als Gast, der einen Link aus WhatsApp öffnet.
  • Abgemeldet: Wer eine HopIn-Seite öffnet und nicht angemeldet ist, geht direkt zur Keycloak-Anmeldung auf auth.hallucinai.de (die Seite gehört edge und ist hier nicht gezeichnet). „Log out“ im Konto-Menü landet auf der Seite „You are logged out.“ mit einem „Log in“; sie leitet nie von selbst weiter.
  • Entfallen: das Raumpasswort (Zeile 7) und die immer sichtbare Teilen-Box; „Invite“ ersetzt sie.
  • Videofläche: in beiden Themen dunkel; Startseite, Vorschau-Seite, Menüs und Endseiten folgen dem Thema.
  • Kacheln: Verlauf mit Umriss = Kamera an, Initialen = Kamera aus. Türkiser Rand = spricht, Balken oben rechts = Verbindung.

  1. Impressum und Datenschutz stehen im Anruf im Menü „More“, einen Tipp entfernt (Lesart von Zeile 4). Empfehlung: ja.
  2. Videofläche auch im hellen Thema dunkel. Empfehlung: ja.
  3. Nur der Host bekommt beim Verlassen die Rückfrage; Gäste gehen sofort. Empfehlung: ja.
